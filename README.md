# MOS-MUSIC

MOS-MUSIC 是一个独立的中文基督教生命诗歌与音乐学习平台。

## 产品定位

> 找歌 → 听歌 → 学歌 → 唱歌 → 爱唱 → 分享 → 一起唱

MOS-MUSIC 不属于 MOS 门训课程系统，也不以 52 周课程、门训课程或课程完成度组织用户体验。

## 当前产品原则

- 前台歌词使用简体中文。
- 以完整歌曲体验为核心：歌曲内容、简谱、歌词、音频、学唱、视唱、示唱、教唱。
- 采用现代、简洁、音乐化、流行风格的界面。
- 精简一级功能，避免把后台能力直接暴露给普通用户。
- 音乐学习本身具有独立价值，不依赖门训课程才能成立。
- 优先把少量歌曲做完整、做真实可用，再扩充曲库。
- 未核实的内容不得臆测；资源状态必须如实呈现。
- Singing Coach 只处理音乐能力，不评价属灵状态。
- Learn / Sight / Teach 是歌曲内部能力，不作为首页复杂导航。
- 不把 52 周讲道、课程、门训路径嵌入歌曲主体验。

## 首批完整歌曲

当前重点生产与真实测试：
- S-0001《奇异恩典》
- S-0002《我灵镇静歌》
- S-0003《耶稣呼召歌》
- S-0004《普世欢腾歌》
- S-0005《一切献上歌》

目标不是“有 100 首”，而是逐首形成完整、可靠、可学习、可传唱的歌曲单元。

## 开发原则

1. 复用现有能力，不重复建立 Player、Learn、Sight、Teach 或教学数据层。
2. 先内容真实可用，再做视觉与扩展。
3. 每次改动都必须经过实际用户路径验收。
4. 真实的谱面、歌词和声音优先于漂亮的状态标签。

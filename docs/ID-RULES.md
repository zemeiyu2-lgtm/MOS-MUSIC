# MOS-MUSIC｜ID 规则（ID Rules）

Version: V1.0 ｜ 所有 ID 一律 ASCII，前缀 `MUS-`，全系统唯一。

## ID 空间

| 实体 | 格式 | 示例 |
|---|---|---|
| 歌曲 | `MUS-S-NNNN`（4 位序号） | `MUS-S-0001` |
| 课程（24 课） | `MUS-C-NN`（01–24，固定映射 24 主题） | `MUS-C-14`＝彼此饶恕 |
| 七步单元 | `MUS-C-NN-SN`（N=1–7，读明唱记感行传） | `MUS-C-14-S3`＝唱 |
| 主题 | `MUS-T-<层级>` | `MUS-T-L1` / `MUS-T-L2` / `MUS-T-L3` |
| 培训表 | `MUS-F-NN`（01–06 固定） | `MUS-F-03`＝七步法带领 |
| 实践记录 | `MUS-PR-<时间戳>` | `MUS-PR-1726880000` |
| 反馈记录 | `MUS-FB-<时间戳>` | `MUS-FB-1726880000` |
| 映射条目 | `MUS-MAP-NN`（V1.0 固定 24 条） | `MUS-MAP-14` |
| 版本 | `MUS-V-x.y.z` | `MUS-V-0.1.0` |

## 固定映射（不得改动）

- `MUS-C-01…04` ＝ 认识神：创造 / 圣洁 / 慈爱 / 信实
- `MUS-C-05…08` ＝ 认识基督：道成肉身 / 十字架 / 复活 / 跟随基督
- `MUS-C-09…12` ＝ 新生命：悔改 / 信心 / 圣洁生活 / 祷告
- `MUS-C-13…16` ＝ 共同体：彼此相爱 / 彼此饶恕 / 彼此服事 / 合一与教会
- `MUS-C-17…20` ＝ 生活：家庭 / 工作与责任 / 苦难与盼望 / 爱邻舍
- `MUS-C-21…24` ＝ 使命与传递：见证基督 / 万民与宣教 / 训练别人 / 门徒再生产

## 七步序号（MUS-C-NN-SN 的 SN）

1 读 ｜ 2 明 ｜ 3 唱 ｜ 4 记 ｜ 5 感 ｜ 6 行 ｜ 7 传

## 隔离规则

- MOS-MUSIC 的 IndexedDB 库名固定 `mos-music`，SW 缓存名固定 `mos-music-*` 前缀。
- **禁止**读写 MOS-DIS 的 `mos_state_*` / `mos_user` 等 key（CI 硬校验）。
- 映射引用外部体系一律用 ID（`MOS_Week`、`LQ`），不复制其内容数据。

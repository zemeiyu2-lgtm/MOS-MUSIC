## 全库原则

1. 先把一批歌真正做成可唱、可学的成品，再扩数量。
2. 伴奏不限定钢琴：先求完整、合适、好唱；有真实可用的不同版本再提供选择。
3. 歌词、简谱、示唱、伴奏、时间轴、教唱资源缺哪项就明确显示“尚未提供”。
4. 生产队列不等于神学评价，也不改变 100 首正式选曲范围。
5. 版权与来源逐首落实；选入 100 首不等于版权已经清楚。

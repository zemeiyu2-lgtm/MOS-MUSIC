# MOS-MUSIC｜UI REDESIGN V2.2 视觉设计冻结稿

> 状态：Design Frozen
> 目标：把 MOS-MUSIC 从「温暖的教会学习网站」升级为「当代音乐 App」
> 范围：前台视觉与交互语言；不改变既有内容模型、播放器、简谱、学习引擎、离线能力与数据治理边界。

## 一、产品视觉定位

MOS-MUSIC 不再采用传统教会网站 / 教学平台的视觉语言。

核心方向：

> 现代音乐播放器范式 + 编辑感 + 音乐沉浸 + MOS 独有简谱学习

> 现代的是产品语言，经典的是歌曲内容。

不复制 Spotify / Apple Music / YouTube Music 的品牌视觉，而是吸收成熟音乐产品的共同交互范式，再建立 MOS-MUSIC 自己的视觉身份。

## 二、四个核心词

音乐优先 / 大留白 / 强字体 / 少边框

禁止重新回到：教会门户感、神学院门户感、课程后台感、SaaS 仪表盘感、大量边框卡片、大量胶囊按钮、过多状态标签、Emoji 功能图标泛滥。

## 三、整体视觉语言

基础背景采用中性浅灰白与真正的深黑夜间模式；现代无衬线为主，歌曲标题大、重、紧凑；圆角和阴影克制使用。

## 四、色彩系统

MOS-MUSIC 本身不再以绿色 + 金色作为全站强品牌配色。

基础界面：#F7F7F5 / #0D0D0D / #151515。

歌曲自己决定 Accent，主要来自歌曲封面。Accent 只用于播放按钮、当前状态、当前歌词、当前谱面和少量交互反馈。

> 歌曲决定颜色，音乐决定气氛，界面保持克制。

## 五、一级导航

桌面：诗歌本 / 学习 / 我的歌。左侧栏保持，但轻量化；当前项清晰，不使用厚重色块。

移动：折叠或底部导航，信息架构不变。

## 六、首页

首页不是 Dashboard，而是音乐空间。

核心：大封面、大标题、直接播放、现在唱、最近唱过、进入诗歌本。

首页首先让人听歌，不让人读系统说明。

## 七、诗歌本

诗歌本不做数据库感界面。桌面采用大封面网格与简洁歌曲列表；手机以单列音乐列表为主。

搜索与筛选保留，但属于辅助发现机制。不得用「最好 / 热门 / 推荐」表达价值排序。

## 八、歌曲页

歌曲页采用 Now Playing 思路。

第一屏：返回 → 大封面 → 歌曲名 → 英文副标题（有则显示）→ 播放 → 收藏 → 分享 → 当前进度 → 伴奏 / 示唱选择。

用户进入歌曲页的第一感觉必须是「我正在进入这首歌」，而不是「我正在查看一份歌曲资料」。

## 九、伴奏

伴奏不限定钢琴。

第一原则：先有完整。至少一种真实可用、完整覆盖全曲、节拍稳定、适合独立歌唱的伴奏。

第二原则：有得选择再选择。同一首歌有多个真实可用版本时提供选择。

可能的类型：钢琴、吉他、原声、乐队、管弦、风琴等。

> 合适 → 完整 → 好唱 → 与歌曲音乐性相称 → 有条件再提供更多选择。

## 十、歌词

歌词属于音乐体验，不再做普通文本卡片。播放时当前句高亮，非当前内容降低权重；深夜模式采用沉浸式大字阅读。

## 十一、简谱

简谱是 MOS-MUSIC 与普通音乐播放器最重要的区别。

简谱不是附件、不是 PDF、不是后台资料，而是歌曲主体验的一部分。

播放时可联动当前小节、当前乐句、当前歌词；没有真实时间轴时绝不猜测。

## 十二、学习页

学习页采用播放器模式，不采用课程模式。

前台核心动作：听 → 跟 → 伴 → 自己唱 → 再唱。

十步教学法保留在引擎与内容层，前台采用渐进式呈现，不把完整教学结构一次摊开。

## 十三、看谱唱

看谱唱是 MOS-MUSIC 的核心特色入口。

视觉重点：简谱、起音、拍号、当前句、伴奏。

原则：先看谱，再开口。

## 十四、教别人

教别人不是后台管理模块，而是简单的真实教学动作：找句、看谱、打拍、读词、示范、跟唱。

## 十五、图标

逐步移除 Emoji 作为主要功能图标，统一使用轻量 SVG 图标：Play、Pause、Heart、Share、Search、Music、Headphones、Microphone、Repeat、More 等。

## 十六、动画

只保留三类核心动画：播放状态、当前音乐内容、页面切换。

默认尊重 prefers-reduced-motion；禁止大量卡片逐个跳入。

## 十七、深夜模式

采用真正的音乐沉浸模式：#0D0D0D 背景，封面成为主要色彩来源，减少边框与状态标签，突出封面 + 歌名 + 音乐 + 歌词 / 简谱。

## 十八、响应式

手机：单手使用。平板：浏览与播放并行。桌面：导航、内容与播放状态并行，但不简单把移动卡片横向拉宽。

## 十九、组件控制

减少信息卡片、Chip、Pill、边框、阴影、Emoji icon。

优先使用大标题、大封面、音乐列表、空间、分隔线、播放状态、当前内容高亮。

## 二十、MOS-MUSIC 独有识别

视觉识别来自：经典歌曲内容、当代音乐 App 体验、简谱、学唱、看谱唱、歌曲驱动的视觉 Accent。

> 经典的歌 + 现代的播放器 + 真正可以唱的谱

## 二十一、不变的工程能力

视觉重构不得破坏 IndexedDB、离线能力、Service Worker、播放器、多速度、循环、单句循环、简谱、真实时间轴、光标、Learn / Sight / Teach、Singing Coach 边界、100 首曲库、资源真实性、版权边界、内容与程序分离。

## 二十二、V2.2 验收标准

1. 第一次打开就感觉这是音乐 App。
2. 明显减少传统 Web / 教学平台感。
3. 歌曲封面成为视觉核心。
4. 播放成为自然主动作。
5. 伴奏成为真实音乐选择。
6. 简谱像音乐体验而不是资料页面。
7. 学唱像使用音乐产品而不是上课。
8. 手机端自然单手操作。
9. 深夜模式具有真正沉浸感。
10. 经典歌曲能够自然进入当代产品。

# MOS-MUSIC｜100 首正式选曲库 V1.0

## 定位

本文件是 MOS-MUSIC 前台正式曲库的**选曲范围**。100 首歌曲已从候选层正式写入选曲层，前台显示为「已选曲目」。

选入不等于资源完成，也不等于版权清楚或神学辨识完成。当前统一保持：
- 辨识：NOT_YET_ASSESSED
- 版权：SOURCE_REQUIRED
- 歌词 / 简谱 / 示唱 / 伴奏：逐首建设，不虚构

## 选曲原则

1. 经典与当代内容并存。
2. 覆盖主要主题与真实使用场景。
3. 兼顾个人、主日、门训、使命等使用需要。
4. 先建立 100 首稳定产品范围，再逐首做完整资源。
5. 顺序不是推荐、评分或排名。

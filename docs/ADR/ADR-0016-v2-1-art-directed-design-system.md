# ADR-0016｜艺术化设计系统与前后台视觉彻底分层（V2.1）

- 状态：Accepted
- 日期：2026-09-21
- 关联：ADR-0015（前台/后台分层与候选库）、CI-0024（精选轮换与初分类为展示层约定）
- 范围：**仅程序层与展示层**。零内容数据改动、零 schema 改动、零基线漂移。

## 背景

V2.0 完成了前台三入口与学唱/教唱/传唱的功能闭环，但视觉仍是「工程页面」气质。
V2.1 的目标：把产品变成「现代音乐 App × 教会诗歌本 × 生命门训工具」——
酷、雅、温暖、有音乐感，用户打开的感觉是「这里有歌，我想听一下」，而不是「进入了一个数据库」。

## 决策

### 1. 设计系统（`app/ui/v21.css`，Design Tokens 统一来源）

- **色彩**：MOS 米白/暖灰/深墨为基础；柔和金 `--gold` 作强调色（敬拜气质，非娱乐高饱和）；
  状态色仅绿（成功）/蓝（信息）/红（错误）少量使用。
- **深夜沉浸模式**：`data-mood="night"` 全站切换（头部 ☾/☀ 按钮），偏好存 IndexedDB
  `user_prefs`（**不使用 localStorage**，遵守项目存储铁律），歌词/播放区在深夜模式下对比度单独调校。
- **字阶**：Display/H1/H2/H3/Body/Caption/Button/**Lyrics**（歌词单列一阶：大字号、宽行距、当前句高亮过渡）。
- **动效（全部轻量）**：播放钮呼吸、页面淡入、当前句过渡、收藏心形、分享成功反馈、卡片 hover、
  播放中声波微动画。原则：动效服务于音乐感，不做游戏感。
- 统一 Loading / Empty / Error / No Resource / Playing / Saved / Copied 状态样式，
  杜绝空白、undefined、NaN、生硬英文与技术错误外露。

### 2. 系列化艺术封面（`app/front/covers.js`）

- 无任何外部图片素材：纯 SVG 生成，抽象光影/山/水/光/星空意象。
- **视觉语言由内容驱动**：程序不内嵌主题词（前台程序文件禁 24 课主题词，validate 硬检查），
  封面按 `song_id` 哈希在语言索引内确定性选择变体 + 按歌曲主题（内容层数据）取色相——
  同主题成系列、同系列不千篇一律。
- 明确不做 stock-photo 风格，不引入任何需授权的素材。

### 3. 统一 MusicPlayer（`app/front/player.js`）

全站唯一播放器组件：play/pause/seek（进度条 role=slider + aria-valuenow）/速度 0.5·0.75·1.0/循环/
资源类型（示范/伴奏）/当前句回调。首页、歌曲页、Learn、Teach 共用同一实例语义——
用户从歌曲页进入学唱「不感觉换了一个软件」。无音频资源时优雅降级：
**「音频尚未提供」如实显示，绝不模拟播放**。

### 4. 页面重构（保留 V2.0 全部功能与路由）

- **首页**：大型 Hero Card（今天一起唱：封面/双语/▶现在唱/♡收藏/学唱）+ 快速操作（听一遍/学一节/陪我唱）
  + 继续唱 + 今天只学一节 + 生命诗歌本入口 + 一句「唱歌理由」（确定性轮换，非推荐，延续 CI-0024 口径）。
- **歌曲本**：大小卡片混合 + 封面 + 音乐 App 式搜索（中文/English/Song ID）+ 全部/收藏/正在学/最近/主题/场景。
  前台不出现 source_required / not_yet_assessed / calibration 等后台词。
- **歌曲页九段**：01 Hero → 02 播放区 → 03 陪我唱 → 04 歌词（视觉中心，点击选句）→ 05 唱 →
  06 懂 → 07 活 → 08 教·传（含我跟孩子唱/我和团契一起唱轻入口）→ 09 链接（后台研究档案）。
- **Learn/Teach**：大舞台卡片，每步只有一个核心任务 + 五步全标签进度（1 2 3 4 5，无考试感）；
  Learn 完成后给「再唱一次」与「分享给一个人」；Teach 开场即「不用懂乐理，也可以教别人唱」。

### 5. 前后台彻底分层（强化 ADR-0015）

- 后台路径全部保留且可继续专业化：`#/song-detail`（八段研究档案）、`#/production`、`#/week`、
  `#/library`、Calibration、Governance。
- 前台只说「为什么值得唱」；分数、辨识证据、治理状态只存在于后台。

## 硬边界（本轮再次确认未动）

Frozen Skill、W01–W04、候选库 100 首（NOT_YET_ASSESSED / SOURCE_REQUIRED、无排序/评分/推荐字段）、
升层试批 5 首、Calibration 全部**逐字节不变**。`immutable_drift = []`。

## 验收

validate 0/0（含前台禁词与 SW v9 预缓存硬检查）｜smoke 250/250｜platform-tests 94/94｜
regression 70/70 `immutable_drift=[]`｜derive / song-discernment / guard 通过｜
CDP 113/113（含 V2.1 前台断言、360/390/430/1366 视口、离线冷启动）。

## 残留

- 音频/歌词/歌谱资源仍为 0 条实际文件（结构就绪，「尚未提供」如实降级）。
- 封面为程序生成的抽象视觉；若未来引入人工设计封面，须走资源层（RECORDING 之外的视觉资源槽）与版权核验。
- 深夜模式偏好存 IndexedDB，首次访问由默认亮色渲染，读取偏好后切换（无闪烁处理依赖 SW 预缓存速度）。

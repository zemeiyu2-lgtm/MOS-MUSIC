# ADR-0002｜与 MOS-DIS 五步流程并列（H-1 裁决）

状态：已接受（用户裁决 B）｜ 日期：2026-09-21

## 决定

两套流程并列，边界明确：

| 系统 | 流程 | 定位 |
|---|---|---|
| MOS-DIS | 经文 → 反思 → 选择 → 实践 → 完成 | 每日门训行为流程 |
| MOS-MUSIC | 读 → 明 → 唱 → 记 → 感 → 行 → 传 | 音乐门训形成流程 |

禁止：删除/扩展 MOS-DIS 五步；改 MOS-MUSIC 七步；把两套流程合并。

## 理由

二者回答不同问题：MOS-DIS 管"今天有没有做"，MOS-MUSIC 管"这首音乐正在帮助门徒
成为怎样的人"（§1）。强行统一会让至少一方失真。

## 后果

- 七步法是 MOS-MUSIC 唯一核心音乐门训流程（§3），UI/数据只此一套（步骤条 7 段）。
- 未来允许 MOS-DIS 调用 MOS-MUSIC 内容（接口：内容 JSON + ID），但流程互不侵入。
- MOS-MUSIC 不实现每日五步，也不展示五步入口。

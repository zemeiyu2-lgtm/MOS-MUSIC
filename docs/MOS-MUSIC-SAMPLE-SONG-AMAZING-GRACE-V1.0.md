## 伴奏标准

不再限定钢琴。

标准是：

> 先有一种完整、合适、稳定、好唱的伴奏；
> 有多种真实可用版本时，再提供选择。

因此以后可使用钢琴、吉他、乐队、风琴、原声、管弦等。

## 资源真实性

缺少资源时：

**尚未提供**

不能用：

- 假 URL
- 假音频
- AI 冒充真人
- 推测的时间码
- 未核验的中文译本
- 未听校的谱面宣称为 VERIFIED

## 教学内容

教学内容分成两个层面：

### 可以由现有谱面 / 歌词直接产生的内容

例如：

- 调
- 拍号
- 起音
- 音域
- 长音
- 一字多音
- 乐句边界
- 呼吸提示
- 基础咬字
- 音准与节奏提醒

### 必须真实资源才能完成的内容

例如：

- 真人教唱
- 真人分句示范
- 真人完整示唱
- 真人表达参考

前者可以进入数据库；后者必须等真实资源进入。

## 这一首最重要的结果

《奇异恩典》现在不是“资料最多的一首歌”，而是第一首把以下链路跑通的样板：

**歌曲身份 → 资源 → 简谱 → 时间轴 → 学唱 → 音乐技术提示 → 内容理解 → 生活实践 → 传唱**

后续歌曲不再重新设计产品结构，只逐首填充真实内容。

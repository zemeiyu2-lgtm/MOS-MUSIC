## 伴奏标准

不再限定钢琴。

标准是：

> 先有一种完整、合适、稳定、好唱的伴奏；
> 有多种真实可用版本时，再提供选择。

因此以后可使用钢琴、吉他、乐队、风琴、原声、管弦等。

## 资源真实性

缺少资源时：

**尚未提供**

不能用：

- 假 URL
- 假音频
- AI 冒充真人
- 推测的时间码
- 未核验的中文译本
- 未听校的谱面宣称为 VERIFIED

## 教学内容

教学内容分成两个层面：

### 可以由现有谱面 / 歌词直接产生的内容

例如：

- 调
- 拍号
- 起音
- 音域
- 长音
- 一字多音
- 乐句边界
- 呼吸提示
- 基础咬字
- 音准与节奏提醒

### 必须真实资源才能完成的内容

例如：

- 真人教唱
- 真人分句示范
- 真人完整示唱
- 真人表达参考

前者可以进入数据库；后者必须等真实资源进入。

## 这一首最重要的结果

《奇异恩典》现在不是“资料最多的一首歌”，而是第一首把“正式内容生产 + 资源真实性闸门”跑通的样板：

**歌曲身份 → 资源 → 简谱 → 时间轴 → 学唱 → 音乐技术提示 → 内容理解 → 生活实践 → 传唱**

后续歌曲不再重新设计产品结构，只逐首填充真实内容。


## 本次优化后的关键规则

### 外部真人来源 ≠ 已提供示唱

只有能够在应用内实际播放、且来源/分段/教学适用性已经确认的资源，才记为：

`PROVIDED`

外部链接即使已经找到，也只记为：

`CANDIDATE_EXTERNAL`

它可以进入资源候选池，但**不计入 L3/L4**。

### 中文歌词采用“两层制”

正式歌曲层只使用已经核验、已经授权的中文歌词。

生产阶段可以另存：

`lyrics-zh-working-draft.json`

用于检验：

- 是否适合旋律
- 是否适合弱起
- 是否适合长音
- 是否适合一字多音
- 是否适合普通华人会众唱

工作稿审核完成前，不进入正式歌词槽位。

### L2 就可以是一个真实可用的歌

《奇异恩典》当前先以 L2 为标准样板：

**歌词 + 简谱 + 伴奏**

这已经能够支持普通使用者看谱、听伴奏、自主歌唱。

真人示唱、分句示范、完整教唱属于下一层资源，不应为了“看起来完整”而虚构。

## 当前样板结论

因此，“模板完成”不等于“所有资源都必须有”。

真正完成的是：

> **生产模型完成、真实性闸门完成、最低可用产品完成、缺失资源有明确入口。**

以后 99 首歌曲都按这个标准生产。

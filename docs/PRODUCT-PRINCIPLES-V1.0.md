# MOS-MUSIC 产品原则 V1.1

## 一、独立性

MOS-MUSIC 是独立产品。

它可以与 MOS 其他项目在技术或研究层面共享基础能力，但前台产品不与门训课程绑定。

禁止：
- 以 52 周课程作为歌曲主导航。
- 在歌曲页面显示课程依赖。
- 以课程完成推动音乐学习。
- 把歌曲解释成某一门训课程的附属材料。

歌曲本身就是完整的音乐学习单元。

## 二、用户核心路径

### 普通用户

诗歌本 → 找到歌曲 → 听 → 学 → 唱

### 进阶用户

歌曲 → 简谱 → 视唱 → 独立唱

### 教师

歌曲 → 乐句 → 示范 → 教唱提示 → 带人唱

## 三、导航与界面结构

MOS-MUSIC 采用现代音乐产品常见的**左侧栏导航**作为主要桌面端结构。

原则：
- 左侧栏负责稳定、低认知负担的一级导航。
- 主内容区负责歌曲、学习和播放。
- 不使用复杂的课程树、仪表盘或后台式多级导航。
- 一级入口保持少而清楚。
- 移动端可将左侧栏折叠为简洁的移动导航，但不改变信息架构。

建议一级入口：
- 诗歌本
- 学习
- 我的歌

歌曲内部：
- 听
- 学
- 唱

专业能力通过歌曲内部状态进入，不抢占首页。

## 四、视觉与音乐定位：现代产品语言 + 经典内容

MOS-MUSIC 的“现代”主要体现在**产品语言、交互、视觉和使用方式**，而不是把经典诗歌强行改造成流行音乐。

核心定位：

> **经典不过时，现代仍需要经典；经典可以自然地进入现代人的生活。**

因此平台同时接受两种事实：

1. 音乐产品必须具有当代感：
   - 简洁
   - 流畅
   - 有节奏感
   - 现代排版
   - 清晰动效
   - 年轻但不过度炫技

2. 歌曲内容可以是经典传统诗歌：
   - 经典圣诗
   - 传统中文诗歌
   - 新的生命诗歌
   - 当代创作

不要求经典歌曲“变成流行歌”才算现代。

真正现代的是：
- 用户如何找到它
- 用户如何听它
- 用户如何学习它
- 用户如何唱它
- 用户如何把它带进今天的生活

视觉关键词：

现代 / 简洁 / 音乐化 / 流动 / 有呼吸感 / 温暖 / 克制 / 流行音乐产品感

避免：

厚重课程后台感 / 表格感 / 管理系统感 / 神学院门户感 / 复杂仪表盘感 / 为了“现代”而过度视觉炫技。

## 五、内容完整性

完整歌曲单元至少应逐步具备：

1. 简体中文歌词
2. 正式简谱
3. 可播放声音
4. 钢琴练习
5. 示唱
6. 乐句结构
7. 学唱
8. 视唱
9. 教唱

只有资源真正存在并通过验证，才显示“可用”。

## 六、内容原则

英文标题可以作为内部来源检索字段，但前台歌曲内容以简体中文为准。

缺少的内容：
- 不虚构
- 不伪造
- 不用“资源存在”代替“用户可以使用”

经典歌曲与新歌采用同一套完整内容标准。

## 七、AI 边界

Singing Coach 可以辅助：
- 音准
- 节奏
- 延音
- 咬字
- 强弱
- 表达

不得评分：
- 属灵程度
- 敬拜真诚度
- 灵命状态
- “更属灵”的程度

## 八、工程原则

- 优先复用已有 Player。
- 优先复用已有 Learn / Sight / Teach。
- 优先复用现有 teaching 数据层。
- 不建立重复数据层。
- 真实媒体必须经过浏览器实际播放/渲染验收。


## 九、伴奏原则

音乐有时代个性，因此 MOS-MUSIC 不把钢琴规定为唯一伴奏形式。

伴奏标准只有两个层次：

1. **先有完整**：一首可以正式学习的歌，至少要有一种适合这首歌、完整覆盖全曲、节拍稳定、能够支持独立歌唱的伴奏。
2. **有得选择再选择**：当同一首歌有两种或以上经过核实、真正可用的伴奏时，前台提供选择；可以是钢琴、吉他、乐队、原声编配、管弦、风琴等，具体取决于歌曲与可用资源。

选择依据不是“越现代越好”，而是：**是否合适、是否完整、是否好唱、是否与这首歌的音乐性相称**。

经典歌曲可以保留经典的音乐气质；现代歌曲也可以采用当代编配。现代产品负责让人容易找到、容易选择、容易使用，而不是强迫所有歌曲采用同一种伴奏风格。

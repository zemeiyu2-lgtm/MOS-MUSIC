# MOS 生命诗歌｜歌曲教学法 V1.0

> 状态：**Frozen**（V3.0 标准层）
> 适用范围：MOS-MUSIC 全部歌曲的前台教学（学唱 / 视唱 / 教唱）
> 机器词表：`content/song-units/index.json` → `teaching_method` / `learner_stages` / `review_cycle`
> 关系：本文档是**规范性来源**；词表与前台是它的机器表达，二者冲突时以本文档为准并须修词表。

---

## 一、教学总目标

MOS 音乐教学的目标**不是培养音乐专业人才**，而是让一个普通人：

1. 能够**照着简谱自己唱**一首歌（不需要有人在旁边带）；
2. 能够**把这首歌教给另一个人**（不需要懂乐理）；
3. 在反复唱的过程中，让这首歌的真理**进入生命**（唱 → 记 → 行 → 传）。

三句话概括：

> **看得懂谱 → 张得开口 → 教得出去。**

音乐不是装饰，也不是表演项目。它是**真理的载体**与**共同体之间的传递媒介**。
因此本教学法的评价标准不是「唱得多好」，而是「**能不能自己唱、能不能教别人**」。

### 与门徒训练的关系（本 V3.0 的定位）

- 歌曲**可以相对独立地完成门训功能**，不必然绑定在某一周经文 / 某一课之上。
- 周次与课程是**一种可能出现的使用场景**，不是歌曲成立的前提。
- 因此本教学法**不从周次出发**，只从「这首歌本身」出发：谱 → 声 → 词 → 合成 → 独立 → 教会别人。
- 一首歌被唱熟、被教出去、在生活里被用起来，门训就已经在发生。

## 二、八条基本原则

| # | 原则 | 含义 |
|---|---|---|
| 1 | **先看谱，再听声** | 不把「听会」当成「学会」。视唱模式默认不给完整示范。 |
| 2 | **一句一句，不整首灌** | 分句处理；能唱一句就够开始。 |
| 3 | **钢琴是唯一的伴奏** | 不使用其他乐器编配，保证任何场合（家庭 / 小组 / 教室）可复现。 |
| 4 | **不评价嗓音，只评价方向** | 不说「唱得不好」；只说「这一句往这里走一点」。 |
| 5 | **不用专业术语吓人** | 说「从哪里开始」「哪里换气」，不说「调式内声部功能」。 |
| 6 | **次数少、间隔开** | 今天唱一次，过两天再唱，比一次练到熟更有用。 |
| 7 | **能教才算会** | 教学的最高检验是**你把这首歌交给了另一个人**。 |
| 8 | **不设通过 / 不通过** | 没有考试、没有评分、没有排行榜、没有徽章。只有「我现在到哪一步」。 |

## 三、教学十步法（标准顺序）

十步法**不是十段视频**，而是一条从上到下的顺序：先知道唱什么，再让身体准备好，
再分别处理谱、节奏、视唱、词，最后合成、示唱、自主歌唱，并迁移到独立视唱与教别人。

三个模式（学唱 / 视唱 / 教唱）是**同一首歌的三种使用方式**，不是三套流程 ——
每一步标明它出现在哪些模式里（见下表 `模式` 列）。

| 步 | key | 名称 | 这一步要达到的目标 | 出现在 |
|---|---|---|---|---|
| 01 | `know_song` | 认识歌曲 | 先知道我要唱什么（歌名、来源、这首歌在说什么）。 | 学唱 / 视唱 / 教唱 |
| 02 | `warm_body` | 准备声音与身体 | 让身体准备好唱（站直、放松、深呼吸）；**不做专业声乐训练**。 | 学唱 / 教唱 |
| 03 | `teach_score` | 教谱 | 普通人也能看懂这首歌的谱：调、拍号、第一音在哪里。 | 视唱 / 教唱 |
| 04 | `teach_rhythm` | 教节奏 | 身体先认识节拍（拍手 / 走路 / 打点）。 | 视唱 / 教唱 |
| 05 | `sight_singing` | 视唱训练 | 看谱 → 内听 → 唱；**此时暂时关闭示范**。 | 视唱 |
| 06 | `teach_words` | 教词 | 先把词说顺，再把词唱进去。 | 学唱 / 教唱 |
| 07 | `combine` | 词曲合成 | 音高 + 节奏 + 歌词合在一起。 | 学唱 / 教唱 |
| 08 | `live_demo` | 真人示唱 | 示范正确的声音与音乐表达。 | 学唱 / 教唱 |
| 09 | `sing_alone` | 自主歌唱 | 关掉示唱，只剩钢琴，自己唱。 | 学唱 |
| 10 | `independent` | 独立视唱 + 教别人 | 只给简谱与起音，自己唱；并向别人示范怎么看谱、怎么打拍、哪里换气。 | 学唱 / 视唱 / 教唱 |

**第 01 步的限定**：认识歌曲**不是视唱训练**（机器字段 `not_sight_training: true`）。
它只是让人知道「我在唱什么」，不进入读谱与音准训练。

## 四、三种模式

同一首歌的三种使用方式。它们的差别在**示范出现的时机**，不在曲目。

### 4.1 学唱（`learn`）

- **适合**：第一次学一首歌。
- **原则**：听 → 跟 → 陪 → 自己唱。
- **示范时机**：**一开始就给完整示范**（`gives_full_demo_first: true`）。
- **可用资源**：男声 / 女声 / 钢琴 / 慢速 / 分句 / 循环。

| 序 | key | 名称 | 提示 |
|---|---|---|---|
| 1 | `listen` | 听 | 先听一遍，找到调子，不急着跟。 |
| 2 | `repeat` | 跟 | 跟着示唱一句一句跟，唱不准就重来。 |
| 3 | `accompany` | 陪 | 开钢琴陪唱，和伴奏一起唱。 |
| 4 | `self` | 自己唱 | 关掉人声，只听钢琴，自己唱一遍。 |
| 5 | `again` | 再唱一次 | 今天多唱一次就够了；过几天再回来唱。 |

### 4.2 视唱（`sight`）

- **适合**：训练音乐能力（读谱 / 音准 / 节奏）。
- **原则**：看谱 → 内听 → 唱 → 核对 → 修正。
- **示范时机**：**默认不先给完整示范**（`gives_full_demo_first: false`）——
  只给起音、节拍与钢琴参考，**最后才播放示唱核对**。

| 序 | key | 名称 | 提示 |
|---|---|---|---|
| 1 | `read` | 看谱 | 先看调、拍号、起音与结构。 |
| 2 | `inner_hear` | 内听 | 看着谱在心里听见它，先不出声。 |
| 3 | `sing` | 视唱 | 看谱唱出来；可以只听起音与节拍。 |
| 4 | `check` | 核对 | 现在才播放示唱，对照自己唱的对不对。 |
| 5 | `fix` | 修正 | 把不稳的一句单独再练一次。 |

### 4.3 教唱（`teach`）

- **适合**：父母 / 小组长 / 主日学教师 / 敬拜同工 / 任何普通信徒。
- **原则**：教唱是**把这首歌交给另一个人**，不是讲解乐理。
- **示范时机**：给完整示范（`gives_full_demo_first: true`）。

| 序 | key | 名称 | 提示 |
|---|---|---|---|
| 1 | `teach_score` | 教谱 | 告诉他这一句怎么看、第一音在哪里。 |
| 2 | `teach_rhythm` | 教节奏 | 一起拍手打拍，先把节拍走顺。 |
| 3 | `teach_words` | 教词 | 先读词、再说词，指出容易唱错的字。 |
| 4 | `demonstrate` | 示范 | 你唱一句给他听，**不要唱整首**。 |
| 5 | `follow` | 跟唱 | 他唱一句，你跟一句，唱不准就再示范。 |
| 6 | `accompany` | 钢琴陪唱 | 开钢琴，让他自己唱，你在旁边看换气。 |
| 7 | `full` | 全曲 | 最后完整唱一遍，唱完给他一点鼓励。 |

**教唱与传唱的分界**：教唱发生在一次真实的教学场合（有人在场）；
传唱是长期结果（这首歌在你之外的人那里被继续唱）。前台只记录次数，不排名次。

## 五、光标跟随标准

光标跟随（进度跟随）是「乐谱明显」的必然要求：唱到哪里，谱上就亮到哪里。

### 5.1 硬规则

1. **只按真实时间标记定位**。光标位置来自分句时间轴（`timeline.phrases[].marks`）里
   **真实存在**的标记（小节 / 拍 / 音符）。
2. **绝不插值**。不得按「音频总长 × 比例」推算当前小节 —— 那会给出**假的精度**。
   没有标记的地方，光标**停在最后一个已知标记**，不往前「猜」。
3. **没有时间轴就不显示光标**。`supportedLevels()` 只列出**真实存在标记**的层级。
   宁可不显示，也不显示一个会骗人的光标。
4. **单调性检查**。标记时间必须非递减；`timelineProblems()` 检测并报出越界 / 逆序。

### 5.2 定位输出

给定播放秒数 `t`，`locate()` 返回：

- `phrase_id`：当前分句；
- `measure`：当前小节（基准可为 `mark`（音符标记）或 `phrase_range`（分句区间），
  在前台标注为「近似」）；
- `note_index`：当前音符；
- `line_id`：当前歌词行（用于歌词区高亮联动）。

## 六、学习闭环

```
读（看谱） → 明（知道在唱什么） → 唱（学唱 / 视唱） → 记（记住） 
   → 感（被这首歌触动） → 行（生活里用起来） → 传（教给别人）
```

- 这个闭环**不出现「竞争」环节**（无比赛、无排名、无晋级）。
- 前台的「生命实践」只做**轻入口**（一个祷告 / 一个行动 / 一个关系 / 一个提醒 / 一个生活操练），
  不替使用者完成表达，也不给标准答案。

## 七、四级学习者状态（非等级）

| 序 | key | 名称 | 含义 |
|---|---|---|---|
| 1 | `know` | 认识 | 我知道这首歌。 |
| 2 | `sing_along` | 会唱 | 我可以跟着唱。 |
| 3 | `sing_alone` | 独立唱 | 没有示范，我也可以唱。 |
| 4 | `can_teach` | 会教 | 我可以教另一个人。 |

**铁律**：

- 四级是**学习路径状态**，**不是排行榜、不是竞争等级、不是分数**。
- 系统**只记录，不评价**：`markStage()` **只增不减**（不降级、不打分、不判定未通过）。
- 系统**不提供通过 / 不通过，不给徽章或奖励**（平台校验器硬检查禁止评分/排名/徽章字段）。
- 前台措辞统一为「我现在到哪一步」，不用「等级 3」「Level 3」这类词。

## 八、分散练习节奏（Day 0 / 2 / 7）

| key | 名称 | 天偏移 | 说明 |
|---|---|---|---|
| `d0` | 首次学习 | 第 0 天 | 今天第一次学。 |
| `d2` | 再唱一次 | 第 2 天 | 隔两天回来唱一遍，比一次练到熟更有用。 |
| `d7` | 第三次唱 | 第 7 天 | 一周后再唱一次，让它留下来。 |

- 间隔**不是「科学的唯一答案」**，而是把「分散练习」的原则变成产品默认节奏。
- 之后随机再遇到，**不催不迫**：到期只提示「该回来唱了」，不制造焦虑、不累计「欠账」。

---

## 九、资源缺失时的诚实降级

- 任何资源缺失（歌词 / 简谱 / 示唱 / 钢琴 / 时间轴 / 光标）一律如实显示为 **「尚未提供」**。
- **不得假装播放**、**不得用合成声音冒充真人示唱**、**不得用占位图冒充乐谱**。
- 教学步骤可以照常列出（步骤是标准），但对应资源缺失时明确标注尚未提供 ——
  **「有步骤、有内容、没资源」是允许且必须被如实表达的三种状态**。

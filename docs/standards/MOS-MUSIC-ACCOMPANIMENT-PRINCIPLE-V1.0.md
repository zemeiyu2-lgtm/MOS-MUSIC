# MOS-MUSIC｜伴奏原则 V1.0

## 核心原则

MOS-MUSIC 的伴奏不以某一种乐器为标准。音乐具有时代个性，而不同歌曲、不同处境、不同使用者也需要不同的音乐支持。

平台采用两级标准：

### 一级：先有完整

一首进入“完整歌曲”生产线的歌曲，至少必须有一种真实可用、完整覆盖全曲、节拍稳定、适合独立歌唱的伴奏。

“有”比“多”重要。没有完整伴奏，就如实显示“尚未提供”；不使用不完整片段冒充完整歌曲支持。

### 二级：有得选择再选择

当同一首歌有两种或以上经过核实、真正可用的伴奏时，前台提供选择。

选择可以包括：钢琴、吉他、乐队、原声编配、管弦、风琴等其他合适编配。

不要求每首歌都拥有多种版本，也不为了“现代”强行加入多乐器。

## 选择标准

伴奏的优先级不是“最炫”或“最现代”，而是：

**合适 → 完整 → 好唱 → 与歌曲音乐性相称 → 有条件时再提供更多选择。**

经典圣诗可以保留经典音乐气质；现代创作也可以使用当代编配。平台现代化的重点是让人容易找到、听到、比较和选择，而不是要求所有歌曲采用同一种声音。

## 对产品的影响

1. 前台统一称“伴奏”，不再把钢琴作为唯一产品概念。
2. 资源层可以有多个 ACCOMPANIMENT 记录。
3. 播放器可以并列显示多种伴奏并让用户切换。
4. 完整度判断首先检查“至少一种有效伴奏”，而不是检查“必须有钢琴”。
5. 旧的钢琴资源继续有效；它只是伴奏选项之一。

> 技术迁移期间，历史 piano 字段保留兼容，不代表产品标准仍要求钢琴。新资源统一按“伴奏”思路建设。

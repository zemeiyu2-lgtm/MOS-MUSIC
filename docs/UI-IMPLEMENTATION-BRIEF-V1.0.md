# MOS-MUSIC UI 重整实施说明 V1.0

本文承接 docs/UI-REDESIGN-V1.0.md。
目标是一次完成前台信息架构重排，最大限度复用现有能力。

## 现有代码观察

1. `index.html` 目前为顶部品牌 + 主内容 + 底部导航。
2. `app/shell.js` 已集中处理导航渲染，适合把现有 NAV_KEYS 改造成桌面侧栏。
3. `app/modules.js` 已有 F1/F2/F3 三个前台入口，继续复用，不删除后台模块。
4. `app/front/home.js` 当前信息块过多，需要明显减法。
5. `app/front/songbook.js` 当前有多层筛选和工程字段，需要简化普通用户视图。
6. `app/front/song-page.js` 当前能力完整，但页面区块过多，需要重新分组，而不是重做播放器。
7. `app/front/learn.js`、`teach.js`、`score.js`、`phrase-card.js` 均应继续复用。
8. `app/front/mine.js` 当前仍露出 Singing Coach 和后台入口，需要降级为次级入口。

## 一、Shell

桌面端：
- 左侧固定/半固定 sidebar。
- 主内容区域自适应。
- 顶部只保留当前页面标题、必要状态和少量设置。
- 不再使用底部导航作为桌面主导航。

移动端：
- 保留底部简洁导航，或折叠侧栏。
- 不另造功能。

侧栏一级入口：
- 诗歌本
- 学习
- 我的歌

侧栏底部：
- 搜索
- 设置

不要把 Coach、门训、课程、生产、治理放入侧栏。

## 二、品牌语言

index.html 的标题、description、品牌副标题需要脱离“音乐门徒训练平台”等课程化表达。

产品语言统一为：
- 中文生命诗歌与音乐学习平台
- 经典与现代共存
- 听 / 学 / 唱

后台技术名称可以保留在代码和后台，不出现在普通用户品牌区域。

## 三、首页

重构 `app/front/home.js` 的信息层级，但不删除底层数据能力。

目标第一屏：
- 一首现在可以唱的歌
- 搜索入口
- 继续学习

把以下内容移出首页主视觉：
- Singing Coach 大卡
- 懂
- 活
- 统计
- 资源状态
- 技术状态
- 课程/周次信息

可保留“最近唱过 / 收藏 / 继续学”，但做成小型列表。

## 四、诗歌本

重构 `app/front/songbook.js` 的显示层。

默认只显示：
- 搜索
- 全部 / 收藏 / 正在学 / 最近唱过
- 歌曲列表

主题 / 处境 / 场景 / 音乐筛选做成可展开的筛选面板。

歌曲卡删除普通用户不可理解的工程信息：
- Song ID
- Tier
- Review Status
- layer
- CI

英文标题只作为歌曲内部次级信息，前台中文歌名优先。

## 五、学习入口

不要新建第二套学习引擎。

侧栏“学习”优先复用现有 songbook 的 learning 数据。

用户点击某首正在学的歌曲后进入现有：
`#/learn/:id`。

如果没有正在学习：
显示简洁空状态并引导到诗歌本。

## 六、歌曲页

重构 `app/front/song-page.js` 的呈现顺序。

不删除现有 Player、Score、Phrase Card 或 teaching data。

建议新结构：

### A. 歌曲头部
- 封面
- 简体中文歌名
- 一句短说明
- 收藏
- 主播放按钮

### B. 主播放器
- 播放 / 暂停
- 进度
- 速度
- 音轨
- 循环

### C. 简谱 + 歌词
- 完整简谱作为视觉主角
- 中文歌词紧邻简谱
- 有时间轴时正常跟随
- 未 VERIFIED 时保持安全门禁

### D. 开始学习
- 学唱
- 看谱唱
- 教别人

只显示短按钮，不再显示三张解释性长卡。

### E. 乐句学习
进入 Learn 后使用现有 66 张 phrase cards。
歌曲主页只显示少量“下一句 / 开始学”入口。

### F. 歌曲内容
懂 / 活 / 背景 / 祷告等折叠为“更多内容”或歌曲详情。

## 七、Singing Coach

保留 `app/coach.js` 及相关数据。

不要作为首页一级功能。

歌曲内部入口使用：
“唱得更准”。

Coach 内部仍然保留十项音乐能力模型。

## 八、我的歌

`app/front/mine.js` 保留：
- 收藏
- 正在学
- 最近唱过
- 教过 / 分享过（若数据已有）

缩小复杂统计。

Coach 变成一个普通入口，不占据主要视觉。

后台入口移至设置或隐藏路径，不在普通“我的歌”页面直接展开生产/治理卡片。

## 九、后台隔离

继续保留：
- courses
- steps
- week
- production
- library
- admin
- song-detail
- 其他研究与治理数据。

但普通前台页面不得出现这些模块的导航链接、周次 ID、课程 ID、治理状态或工程术语。

## 十、不要删除能力

本轮明确禁止删除：
- Player
- Learn
- Sight
- Teach
- phrase-card
- score renderer
- MIDI synth
- Singing Coach
- IndexedDB
- offline
- teaching data
- content governance
- 现有测试。

本轮是信息架构减法，不是功能削减。

## 十一、真实验收

完成后至少验证：

1. 桌面端左侧栏。
2. 移动端导航。
3. 首页只剩音乐核心。
4. 诗歌本可以搜索并快速进入歌曲。
5. 歌曲页首先看到真实播放器和简谱。
6. 歌词为简体中文。
7. Learn / Sight / Teach 均可进入。
8. 现有 149 项真实线上媒体断言继续通过。
9. 不出现 W01 / W02 / 课程或门训字样于普通前台。
10. 后台能力仍可由内部路径访问。

## 十二、完成定义

用户打开后应该马上明白：

> 这里是一个可以听歌、看谱、学歌、唱歌的现代中文诗歌平台。

用户不应该首先想到：

> 这是一个课程、门训或内容治理系统。
